Comment c'est calculé

Seules les lignes de type « Réservation » sont comptées. Un séjour à cheval sur deux mois ou deux années est réparti nuit par nuit. Le brut est le montant payé pour le séjour (ménage compris), hors taxes reversées par Airbnb. Le net est le brut moins les frais de service. Les lignes de versement et de régularisation sont ignorées.
